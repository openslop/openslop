# Security

Found a security problem in OpenSlop or openslop.ai? Thanks for looking.

## Reporting

Please don't open a public issue. Report it privately through [GitHub](https://github.com/openslop/openslop/security/advisories/new) instead, so we can fix it before anyone else finds it.

Tell us what you found, how to reproduce it, and what someone could do with it. A rough report is fine.

## What happens next

We'll reply as soon as we can, usually within a week. Once it's fixed, we'll publish a GitHub Security Advisory and credit you, unless you'd rather stay anonymous.

## Scope

This repo and the hosted app at [openslop.ai](https://openslop.ai) are in scope. Bugs in a provider we call (like Anthropic or ElevenLabs) should go to that provider.
